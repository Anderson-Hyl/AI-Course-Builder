Closing the loop on the session.

The Session Workspace used to dismiss the moment AdaptationEngine.adapt succeeded, hiding the LLM’s analysis behind an instant fade-out. This pass adds a digest card to the existing adaptation overlay so the feedback loop closes inside the workspace before the learner returns to the bigger surface.

Anatomy of the digest

Each region is gated on the LLM’s output — highlights, concerns, concepts, and reviews hide entirely when the proposal carries an empty list, so the card stays calm when the model’s signal is thin. The completion chip color is mapped from proposal.outcome.completion through theme tokens (state.success, state.warning, state.danger); the mastery bars reuse the same progressTrack palette as the lesson’s step rail at the top of the workspace, so the visual language reads consistent across the session lifecycle.

Same overlay, four states

AdaptationStatus is a single enum the workspace switches on: .idle renders nothing and the lesson stays interactive; .running shows the spinner; .summary(AdaptationSummary) shows this digest; .failed(String) shows an error card with Retry / Skip. A small blocksLessonInteraction helper returns true for .running and .summary — both block the Done button so adaptation can’t double-fire and the learner can’t scroll back through blocks mid-flow.

The flow, end to end

From the moment the learner taps Done to the moment Course Home repaints with the completed badge.

Step 1

Done tapped

Reducer flips .running, kicks off adaptationEngine.adapt(sessionID), cancels in-flight tutor stream.

Step 2

Engine round-trip

LLM scores attempts, returns submit_adaptation tool call. Validator checks shape; applier writes mastery, reviews, artifact, then session.completed.

Step 3

Pause on summary

Reducer flips .summary(AdaptationSummary). Workspace stays mounted; overlay swaps from spinner to digest card.

Step 4

Continue → dismiss

Tap drives .continueAfterSummaryTapped; reducer dismisses; didChangeSessions hook refreshes Course Home.

§ 4

The three changes in detail

01

Carry the proposal through to the workspace

The view needs the highlights, concerns, per-concept estimates, and per-review fronts/backs. Re-decoding the persisted Artifact JSON would be wasteful when the validated proposal is already in scope at AdaptationApplier.apply. Adding a single field to the digest avoids the round-trip.

public struct AdaptationSummary: Sendable, Equatable {
    // existing fields …
    public let proposal: AdaptationProposal     // new
}
02

Replace auto-dismiss with a summary state

The previous .completed case was dead the moment the dismiss effect fired. Replacing it with .summary(AdaptationSummary) turns the same enum into a real terminal state — the workspace stays mounted, the overlay paints the digest, and dismiss is gated on the new .continueAfterSummaryTapped action.

public enum AdaptationStatus: Equatable {
    case idle
    case running
    case summary(AdaptationSummary)
    case failed(String)

    public var blocksLessonInteraction: Bool {
        switch self {
        case .running, .summary: true
        case .idle, .failed: false
        }
    }
}
03

Render the digest in adaptationOverlay

The view’s overlay switch already handled .running (spinner card) and .failed (error card with Retry / Skip). The new .summary case renders the digest in the same RoundedRectangle(cornerRadius: 18) + surface.card shell so all three states read as one surface across the workspace lifecycle. Card width caps at 480pt with a scrollable inner list when the LLM’s output is verbose.
