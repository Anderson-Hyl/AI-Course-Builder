Reading Type Signatures

Build the muscle for reading Haskell type signatures aloud — the type tells you almost everything you need.

Concept

Currying turns multi-argument functions into chains

Every Haskell function technically takes one argument. add :: Int -> Int -> Int isn't a function of two arguments — it's a function of one Int that returns a function of one Int that returns an Int. Read right-associatively and the arrows make sense.

add :: Int -> Int -> Int add x y = x + y addFive :: Int -> Int addFive = add 5
