Reading Type Signatures

Let’s decode a few examples and build intuition for how Haskell describes function behavior.

Example 1
length :: [a] -> Int
[a] List of any type
-> Takes as input
Int Returns an Int
Example 2
map :: (a -> b) -> [a] -> [b]
(a -> b) Transform one value
[a] Original list
[b] New list
Practice

Fill in the blank to complete the type signature.

head :: [a] -> ___

Hint: the function returns the first element of a list, not another list.

AI Tutor

Here’s a hint to get you started

Think about what type of value a function like head returns.

Show Hint
Common Mistakes

Confusing input and output types, treating arrows like tuples, or assuming a concrete type too early.

Your Notes
Type signatures are right-associative. The arrow binds to the right, so a -> b -> c really means a -> (b -> c).
