A AI Course Builder

One persistent shell. Always know where you are.

Today every step of the flow renders as its own full-screen page with no back button, so the learner can lose orientation between Goal Intake, Home, the Program Map, and a Session. This redesign borrows SlideFlow's three-pane shell — sidebar on the left, a doc-head toolbar with breadcrumbs at the top of the stage, and a context rail on the right — while reusing every existing token, card, and accent from CourseBuilderThemePalette.swift.

Reading Type Signatures

Let's decode a few examples and build intuition for how Haskell describes function behavior.

Example 1
length :: [a] -> Int
[a] List of any type
-> Takes as input
Int Returns an Int
Example 2
map :: (a -> b) -> [a] -> [b]
(a -> b) Transform one value
[a] Original list
[b] New list
Practice

Fill in the blank to complete the type signature.

head :: [a] -> ___

Hint: the function returns the first element of a list, not another list.

Common mistakes

Confusing input and output types, treating arrows like tuples, or assuming a concrete type too early.

Your notes
Type signatures are right-associative. The arrow binds to the right, so a -> b -> c really means a -> (b -> c).

What carries over to the SwiftUI build

The work needed in AppFeature + LearningUI mirrors SlideFlow's three-pane shell. Every screen below already exists in the codebase; the change is to host them inside one persistent HStack instead of swapping full-screen views.

Promote SidebarShell to the root The current shell wraps Home + Program Map. Move it outside AppView's switch so Goal Intake and Session Workspace live inside it instead of replacing it. currentRoute stays the single source of truth for which view renders in the stage.
Add a DocHead component A 54pt toolbar at the top of the stage column, similar to SlideFlow's DocHead. Owns the breadcrumb (programName › stageTitle › sessionTitle), segmented mode toggles, and primary CTA. Breadcrumb segments are buttons that dispatch routeSelected / stageSelected / sessionSelected.
Introduce a context rail A 264pt right column that is conditionally rendered per route — Today on Home, Selected Stage on Program Map, AI Tutor during a Session, hidden on Goal Intake. Mirrors SlideFlow's pattern of swapping SlideRailView ↔ InspectorView via a Bool guard, not a NavigationStack.
